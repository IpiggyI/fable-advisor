# 其他宿主中的各车道 —— 宿主自己的入口

在其他宿主中第一次派发之前阅读本文。其他宿主指加载本技能、但既不是 Claude Code 也不是 Cursor 的宿主，包括导入 Claude Code 设置或插件、自身运行方式不同的宿主。[SKILL.md](SKILL.md) 中的角色、档位、升级梯、交付契约与核验照常适用。下列规则只替代 SKILL.md 中依赖路由档案的部分。

## 入口

- **只用宿主自己的入口。** 不沿用任何其他宿主的 runner、receipt gate、路由门或型号钉选；只经宿主自己提供的入口派发。宿主加载的插件钩子不作依靠：路由是文本，没有机械校验。
- **宿主运行不了的 agent 文件。** agent 文件写死的型号在该宿主上不能运行时（例如 `advisor-*` 的 `model: fable`），该文件视为不可用的入口。不派它；改用宿主自己提供的入口承担该角色，让这次派发指向该角色所需的执行侧契约，并在披露中说明。
- **执行侧契约。** 派发提示按绝对路径指向其角色所需的前言：`worker` 读 [lane-preamble.md](lane-preamble.md)，`explorer` 或 `advisor` 读 [lane-preamble-report.md](lane-preamble-report.md)。

## 不读档案的路由

不读路由档案。SKILL.md「路由」的阶段 1 照常适用：档位按任务难点与升级梯定，高于 `mainstay` 时派发带有 SKILL.md 接受的一种依据。SKILL.md 中有三处依赖档案，由下列规则替代：阶段 2 的格内选择、「改道」的车道顺序、R2 中不低于失败型号排名的下限。

- **档位按强度分。** 在一个型号上，`mainstay` 用该入口的默认强度，`crux` 比默认高一级，`rescue` 用该入口能给的最高强度。入口不能设强度时，档位只决定契约形状、依据与升级梯，拨盘写裸型号。
- **首次选择。** 用入口的默认型号。宿主提供多个型号时，只在任务落在某个型号的专长上或用户声明了型号时换用，并在披露中说明。
- **改道。** 入口或型号不可用时，换宿主提供的另一个型号，档位与强度规则不变，并披露这次更换；没有别的型号可用时，报告用户。这不算能力失败。
- **R2 与 R3。** 升档按上面的强度规则把强度提高到下一档；宿主提供多个型号时，升档也可以按任务换型号，并披露。R3 按拨盘计数：同一拨盘最多升级一次；没有更高的强度时，交给用户。
- **路由行。** 格式见 SKILL.md「路由」。其中的 `dial` 写宿主实际的型号 id 加强度，或裸型号。

## 会话续用

路由档案没有其他宿主的续用窗口。因此返工票、修正契约与后续消息默认新开会话，带上缺陷、原契约和上轮报告。SKILL.md「会话续用」中超出窗口续用的例外照样适用，那里的其他各条不变。
