# 主会话重复跑全量测试

Status: resolved

## 问题

ADR 0029 把全量测试移到批次之后，车道与 runner 不再跑全量。但 2026-10-12 那次 cc-usage 任务，主会话自己跑了 11 次全量，每次约 6 分钟，合计约 63 分钟：

- 4 次是执行失误：环境变量泄漏导致假红；返工还没落地就开跑；输出经 `tail` 截断后为看失败用例名重跑；`bun run test test/` 误触全量并丢弃输出。
- 3 次本可以只重跑失败的测试文件，或只跑改动涉及的测试文件。
- 三个批次与三次补充需求对应，每个批次都以全量收尾。

cc-usage 在 10-16 加了一条项目规则：批次跑全量时车道不跑测试。它管的是车道里几秒钟的定向测试，管不到主会话的全量复跑。

## 证据

- 逐次清单见 [问题报告第 4 节](../problem-report.md)，由 [tools/full.py](../tools/full.py) 从会话 `e00969a6` 及其子代理记录中提取。
- 之后三个会话（`e092aa18`、`57ff7ceb`、`1ec554cf`）的全量次数分别是 3、1、1。
